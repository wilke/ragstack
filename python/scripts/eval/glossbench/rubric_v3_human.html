Rubric v3. Label every item under these rules; your work is kept in this browser until you export it.

What counts as a symbol: a mathematical symbol or variable of the document, or an abbreviation/alias that the document itself pairs with another name (e.g. "measles virus (MeV)"). A gene, protein or strain name the document never pairs with another name is not a symbol.

Flattened symbols (lost subscripts, "V br" for Vbr): judge by the symbol meant, if the string identifies exactly one symbol in the document. If it stands for two or more (e.g. "br" for both Vbr and Nbr), label it wrong.

correct — definition matches the document, completely and specifically.
partial — definition is true per the document but incomplete, truncated or less specific (or a fuller one appears elsewhere).
wrong — definition is false for this symbol: another meaning, another symbol's definition, never stated, or an ambiguous fragment.
not-a-symbol — ordinary word, unpaired gene/protein name, unit, number, label, code/file/option name, or not in the document in any form.
