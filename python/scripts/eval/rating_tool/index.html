2 · The scale

GradeMeansTest
0 irrelevant The passage does not help answer the question. Same topic is not enough. Ask: could a reader answer anything asked?
1 partially answers Contains part of an answer, or answers a component of the question. You would still need another passage to answer properly.
2 fully answers A reader could answer the question from this passage alone. No further source needed for the question as asked.

The 1-vs-2 boundary is where raters diverge most. The rule is sufficiency, not quality: a terse passage that fully answers is a 2; an eloquent passage that answers half is a 1. See docs/g1-sop-rating.md §2 for worked examples.
