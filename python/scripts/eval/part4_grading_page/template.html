How to grade

Each item shows a user's question, a reference quoted from the documentation, and an answer a model gave. Grade the answer against the reference:

Correct
It states the information in the reference (wording may differ); extra correct detail is fine.
Partial
It states some but not all of the reference information, or for two-part references only one part.
Incorrect
It contradicts the reference or gives different information.
Abstained
It says the documentation does not answer the question.

Keys: 1–4 choose a grade, ←/→ move between items. Your grades are saved in this browser as you go. When you finish, press Export grades and send back the file.
