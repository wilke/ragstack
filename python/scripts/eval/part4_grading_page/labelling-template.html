How to label

Each item shows a user's question and one sentence from the documentation. Decide what the sentence does for that question. Don't think about any answer. Judge only the question and the sentence.

Answer
The sentence states something the user wants to find out, even if only part of it.
Setup
The sentence only describes something the question already says or assumes: a step the user has done or will do, the tool they're using, or the situation they're in. It tells the user nothing they asked to find out.
Neither
The sentence has nothing to do with the question.

How to decide.

  1. Rewrite the question in your head as "The user wants to know: …". What they want to know is the part after "know". Steps written as "after I …", "once I've …" or "when I use …" are the setup.
  2. Ask: if the user read only this sentence, would they learn part of what they want to know? If yes, choose Answer. If it only restates their own setup, choose Setup.
  3. If a sentence does both, choose Answer.
  4. A sentence cut off mid-word still counts. Judge what it says.

Example (made up). Question: "After I upload my reads, how do I choose the reference genome?"

  • "Click Upload to add files to your workspace." → Setup. It describes the step the question already assumes.
  • "Select the reference from the Reference drop-down." → Answer.
  • "The service supports paired-end libraries." → Neither. It is unrelated to choosing a reference.
